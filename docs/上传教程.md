# 发布教程：GitHub / Modrinth / MC百科 / 夸克网盘

> 本文档按顺序操作即可。**开始前先做一件事**：把项目里所有 `YOURNAME` 换成你的 GitHub 用户名
> （涉及 `README.md`、`src/main/resources/fabric.mod.json`），然后重新执行 `./gradlew build`。

---

## 0. 准备好这些文件

| 文件 | 从哪来 | 用到哪 |
| --- | --- | --- |
| `fakeultimine-1.0.0.jar` | `dist/` 或 `build/libs/` | GitHub Release、Modrinth、MC百科、夸克网盘 |
| `fakeultimine-1.0.0-sources.jar` | `build/libs/` | GitHub Release（可选，方便别人看源码） |
| `icon-512.png` | `dist/` | Modrinth 项目图标、MC百科模组封面 |
| `cover-1280x720.png` | `dist/` | Modrinth 画廊图、MC百科截图、README 顶部 |
| 整个 `fakeultimine/` 源码目录 | 本仓库 | GitHub |

发布前自检：

- [ ] `fabric.mod.json` 里的 `homepage` / `sources` / `issues` 已改成你的仓库地址
- [ ] `README.md` 里「下载」小节的 4 个链接已填好（GitHub / Modrinth / MC百科 / 夸克）
- [ ] `./gradlew build` 能通过，`build/libs/fakeultimine-1.0.0.jar` 已更新
- [ ] jar 扔进 `mods/` 实测能加载（日志有 `假人连锁破坏 v1.0.0 已加载`）

## 1. GitHub

### 1.1 建仓库

1. 打开 <https://github.com/new>。
2. **Repository name**：`fakeultimine`
3. **Description**：`让地毯/GCA 假人连锁破坏的 Fabric 附属模组（Minecraft 1.21.1）`
4. 选 **Public**，**不要**勾选 "Add a README file"（我们已经有了）。
5. 点 **Create repository**。

### 1.2 上传源码（两种方式，选一种）

**方式 A：网页上传（不用装 git）**

1. 在新仓库页面点 **uploading an existing file**（或 `Add file → Upload files`）。
2. 把 `fakeultimine` 文件夹里的**内容**全选拖进去（注意是文件夹内容，不是外层文件夹）。
3. Commit message 填 `Initial commit: FakePlayer Ultimine 1.0.0`，点 **Commit changes**。
4. 网页上传会跳过空文件夹（`gradle/`、`.github/` 里的文件能带上，只要拖进去时包含），
   如果 `gradle/wrapper/gradle-wrapper.jar` 没传上去，后面 Actions 会失败——检查一下文件树里有没有它。

**方式 B：命令行（推荐，后续更新方便）**

先安装 Git：<https://git-scm.com/download/win>，然后在 PowerShell 里：

```powershell
cd F:\MCDEEPSEEKMOD\fakeultimine
git init
git add .
git commit -m "Initial commit: FakePlayer Ultimine 1.0.0"
git branch -M main
git remote add origin https://github.com/YOURNAME/fakeultimine.git
git push -u origin main
```

首次 push 会弹浏览器让你登录 GitHub，授权即可。

### 1.3 仓库装修

1. 首页右侧 **About** 齿轮 → 填 Description，**Topics** 填：
   `minecraft` `fabric` `minecraft-mod` `carpet` `fake-player` `ultimine` `chain-break` `1.21.1`
2. **Releases → Draft a new release**：
   - Tag：`v1.0.0`，Target：`main`
   - Title：`v1.0.0 - 首个版本`
   - 描述：可以粘贴 `CHANGELOG.md` 里 1.0.0 那段
   - 附件：上传 `fakeultimine-1.0.0.jar`（可选再传 sources jar）
   - 点 **Publish release**
3. 仓库自带 `.github/workflows/build.yml`：每次 push 会自动编译，推 `v*` 标签还会自动把 jar 挂到 Release 上。
   第一次运行在仓库 **Actions** 页能看到结果（需要仓库设置里 Actions 是启用的）。

> 小提示：如果 Actions 报 `gradlew: Permission denied`，在 Git Bash 里执行
> `git update-index --chmod=+x gradlew` 后提交一次即可。

## 2. Modrinth

### 2.1 创建项目

1. 打开 <https://modrinth.com>，用 GitHub 账号登录。
2. 右上角头像 → **Create a project**。
3. 填写：
   - **Name**：`FakePlayer Ultimine`
   - **Slug**：`fakeultimine`（会成为 `modrinth.com/mod/fakeultimine`）
   - **Summary**（≤256 字符）：
     `让地毯（Carpet）/ GCA 假人像 FTB Ultimine 一样连锁破坏方块，全指令控制，服务端安装即可。`
   - **Project type**：`Mod`
   - **Environment**：勾 **Client** 和 **Server**（功能在服务端，单人游戏也需要它）
   - **License**：`MIT`
4. 上传 **Icon**：`dist/icon-512.png`
5. **Description**：把 `docs/modrinth-描述.md` 的全文粘进去（Markdown 有效）。
6. 保存草稿。

### 2.2 上传版本

1. 项目页左侧 **Versions** → **Create version**。
2. 填写：
   - **Version number**：`1.0.0`
   - **Name**：`1.0.0`
   - **Release channel**：`Release`
   - **Loaders**：勾 `Fabric`
   - **Game versions**：勾 `1.21.1`
   - **File**：上传 `fakeultimine-1.0.0.jar`
   - **Dependencies**：
     - `Fabric API` → **Required**
     - `Carpet` → Optional
     - `Gugle's Carpet Addition (GCA)` → Optional
     - `FTB Ultimine` → Optional
   - **Changelog**：粘贴 `CHANGELOG.md` 的 1.0.0 内容
3. 点 **Publish**。Modrinth 会自动审核，通常几分钟内上线。

### 2.3 画廊图

项目页 **Gallery** → **Add image** → 上传 `cover-1280x720.png`，标题填 `连锁挖掘演示`，设为 **Featured**。

## 3. 夸克网盘（给 MC百科 用的下载地址）

1. 打开 <https://pan.quark.cn>，手机号登录（App 扫码也行）。
2. 点 **上传** → 选择 `dist/fakeultimine-1.0.0.jar`（可以建个文件夹 `FakePlayer Ultimine` 放进去，
   顺便把 `README.md`、`cover-1280x720.png` 一起传，方便玩家看说明）。
3. 在文件上右键 → **分享**：
   - 有效期：选 **永久有效**
   - 权限：**有提取码**（生成 4 位提取码）
4. 点 **创建链接** → **复制链接及提取码**，形如：

   ```
   链接：https://pan.quark.cn/s/xxxxxxxxxxxx
   提取码：abcd
   ```

5. 把这段链接留着，下一步填进 MC百科 的下载地址。

> 注意：网盘链接尽量别改名/移动文件，否则链接会失效；每次发新版本记得回来更新链接。

## 4. MC百科

### 4.1 提交模组

1. 打开 <https://www.mcmod.cn>，注册并登录（建议绑定邮箱，审核沟通要用）。
2. 找到 **提交模组 / 添加模组** 入口（一般在页面底部「提交资料」或右上角用户菜单里，位置可能随改版变化）。
3. 按下面填写：

   | 字段 | 填什么 |
   | --- | --- |
   | 中文名 | `假人连锁破坏` |
   | 英文名 | `FakePlayer Ultimine` |
   | 缩写/别名 | `FPU`、`/ful` |
   | 模组类型 | 辅助类 / 工具类 |
   | 支持版本 | `1.21.1` |
   | 运行环境 | 服务端（客户端可选） |
   | 依赖模组 | 必需：Fabric API；建议：Carpet 或 GCA；可选：FTB Ultimine |
   | 开源地址 | 你的 GitHub 仓库地址 |
   | 模组封面 | `dist/icon-512.png` |
   | 简介 | 粘贴 `docs/mcmod-简介.md` 全文 |

4. 提交后等待审核（一般 1–3 个工作日）。审核员可能会在评论区问细节，及时回复能加快速度。

### 4.2 通过后添加下载地址

1. 进入你的模组页面 → **下载地址** 区域 → **添加**。
2. 先加两条**官方**地址：
   - 类型：`官方` → GitHub Release 链接
   - 类型：`官方` → Modrinth 版本页链接
3. 再加**网盘**：
   - 类型：`网盘`
   - 平台：`夸克网盘`
   - 地址：`https://pan.quark.cn/s/xxxxxxxxxxxx`
   - 提取码：`abcd`
4. 保存。玩家在 MC百科 就能直接看到「夸克网盘」下载按钮。

> MC百科 的简介要客观、别写广告词；带版本号的更新记得同时更新「支持版本」和下载地址。

## 6. 发布之后

1. **改版本号**：`gradle.properties` 里 `mod_version=1.0.1`，`CHANGELOG.md` 加一段，重新 build。
2. **GitHub**：推代码 → 打 tag（`git tag v1.0.1 && git push --tags`）→ Actions 自动发 Release。
3. **Modrinth**：Versions → Create version 上传新 jar。
4. **MC百科**：编辑模组 → 补新版本号与下载地址。
5. **夸克**：上传新 jar，更新分享链接（旧链接如果还在，记得在 MC百科 同步）。
